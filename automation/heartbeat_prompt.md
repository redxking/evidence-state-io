# Advance Evidence-State I/O

Continue the Evidence-State I/O repository as a bounded research program.
Read `AGENTS.md`, `PROJECT_STATUS.md`, `TASKS.md`, `docs/BACKLOG.md`, and relevant
ADRs; inspect local and GitHub state; select one highest-priority unblocked item;
state its claim and disproof test; implement the smallest coherent increment;
run focused and full checks; attempt an adversarial bypass; record exact evidence
and limitations; and push only a coherent verified commit under the repository's
standing authorization. Never infer external validation, production readiness,
release approval, or effect from local tests. Stop at any approval boundary or
after the same unexplained failure repeats twice, preserving the evidence.
