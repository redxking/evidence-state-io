# Release limitations

Evidence-State I/O is a pre-alpha research candidate for synthetic, local, and
authorized shadow evaluation. This release does not establish production
readiness, source truth, cryptographic issuer authentication, trusted time,
independent registry custody, legal sufficiency, certification, operational
effectiveness, customer adoption, or authorization for consequential use.

P0 accepts exactly one required read-only source and rejects multi-source
composition. The replay certificate is unsigned. The included EmptyBench seed
and oracle are implementation-owned and are not a preregistered held-out study
or independent external reproduction. The browser implementation is a
synthetic demonstration reference verified against project-controlled golden
fixtures; it is not the Python runtime or an operational service.
