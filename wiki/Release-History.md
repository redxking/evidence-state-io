# Release history

The repository history preserves the immutable schema 0.1 local baseline and
the active 1.0 candidate development line. Formal GitHub releases are created
only after the exact accepted commit passes local, CI, Pages, Wiki, clean-clone,
security, and publication gates.

Each releasable artifact must include release notes, checksums, an evidence
manifest, an SBOM, provenance attestation, and explicit limitations. The
authoritative history is [CHANGELOG.md](https://github.com/redxking/evidence-state-io/blob/main/CHANGELOG.md)
and the [Releases page](https://github.com/redxking/evidence-state-io/releases).
