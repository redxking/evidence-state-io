# ADR index

The authoritative ADRs are versioned under
[`docs/adr`](https://github.com/redxking/evidence-state-io/tree/main/docs/adr).
They cover the laptop-first modular monolith, versioned JSON and pure evaluator,
fail-closed negative gate, source accounting, canonical certificates, fault
lab, version boundaries, finality, governed profile resolution, replay-record
limits, adversarial hardening, state transitions, and Python trust boundaries.

Accepted ADRs are not silently rewritten. A superseding decision must identify
the prior record, compatibility impact, migration path, and new verification.
