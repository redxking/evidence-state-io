# Deployment models

Supported P0 use is local, offline evaluation through the Python API or CLI.
The same package can run in a laptop VM or disposable container laboratory.
The GitHub Pages browser reference is a synthetic demonstration, not a service
endpoint.

A future read-only sidecar or library integration is plausible, but deployment
into an operational decision path is outside MVP authorization. Any adapter
must preserve profile custody outside producer control and must not introduce
ambient time or network state into deterministic evaluation.
