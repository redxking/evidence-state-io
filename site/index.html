01 / THE PROBLEM

Most systems preserve results. They lose the conditions that make those results meaningful.

An empty response can mean complete absence within a declared scope—or a timeout, hidden population, stale index, unfinished page sequence, inaccessible source, open finality window, or failed query. Those states should never collapse into the same answer.

02 / THE MECHANISM

A small deterministic boundary between observation and assertion.

The gateway does not ask a model to judge whether evidence is complete. It evaluates explicit contracts and produces a replayable record.

  1. 01

    Declare

    Bind the query, scope, access boundary, source, adapter, population, exclusions, and exact governed profile.

  2. 02

    Observe

    Retain source state, coverage, pagination, partitions, timestamps, errors, matches, and query identity.

  3. 03

    Evaluate

    Apply staged trust, coverage, freshness, retention, blind-interval, and derived-finality checks without ambient time.

  4. 04

    Gate

    Permit only a bounded negative with complete support. Every represented partial or contradictory state under the current candidate fails closed.

  5. 05

    Replay

    Issue an unsigned deterministic certificate that separates integrity, replay, expected state, and current local use.

06 / EVIDENCE BOUNDARIES

The project is explicit about what has—and has not—been established.

What the candidate can establish locally

  • A request crossed the named deterministic checks.
  • A decision replays from the retained normalized inputs.
  • An artifact matches separately retained context and digest.
  • A scoped conclusion retained its required qualifications.

What it does not establish

  • Source, registry, profile, issuer, or clock truth.
  • Universal absence, production safety, or legal sufficiency.
  • Authentication, authorization, or non-repudiation.
  • Independent validation, market demand, or operational effect.

08 / FAQ AND GLOSSARY

The distinctions are the product.

Does an empty result prove absence?

No. It becomes a bounded negative only when the declared population, access, coverage, freshness, finality, exclusions, source status, and policy checks pass.

Is the certificate an authorization token?

No. It is an unsigned deterministic replay record. It does not authenticate an issuer, authorize an action, or prove source truth.

Can this run on a laptop or VM?

Yes. The Python 3.11–3.13 core and benchmark are offline and dependency-light. Docker is optional for the disposable fault lab.

What is an evidence state?

A machine-readable description such as present, absent within scope, partial, stale, inaccessible, pending, failed, or contradictory. It is kept separate from disposition, requested action, attempted action, and observed effect.

Scoped negative
A qualified “not found” statement limited to the declared query, population, sources, time, exclusions, and access boundary.
Finality horizon
The declared point through which the source index must advance before a negative can be evaluated.
Replay certificate
A canonical unsigned record binding inputs, contracts, decision, and digest for deterministic comparison.
EmptyBench
A paired synthetic scaffold that holds the visible empty result constant while changing one evidence-sufficiency condition.
